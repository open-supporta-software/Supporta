# Rules Module

Модуль для управления правилами в helpdesk-web приложении.

## Структура

```
rules/
├── index.tsx                    # Страница списка правил
├── create.tsx                   # Страница создания правила
├── create.module.css           # Стили для страницы создания
├── types.ts                    # TypeScript типы
├── constants.ts                # Константы (действия для нод)
├── components/
│   └── CustomNodes.tsx         # Кастомные ноды для ReactFlow
└── README.md                   # Документация
```

## Страницы

### 1. Список правил (`/rules`)

**Компоненты:**
- Заголовок страницы
- Таблица с правилами (из `@open-condo/ui`)
- ActionBar с кнопкой "Добавить правило"

**Колонки таблицы:**
- Название
- Описание
- Дата создания
- Статус (Активно/Неактивно)

**Функционал:**
- Просмотр списка правил
- Переход к созданию нового правила
- Переход к редактированию правила (клик по строке)

### 2. Создание правила (`/rules/create`)

**Компоненты:**
- Заголовок страницы
- Поле "Название"
- Поле "Описание"
- Кнопки для добавления нод
- ReactFlow viewport с кастомными нодами

**Типы нод:**

1. **Триггер** (синий)
   - Новый тикет создан
   - Тикет обновлен
   - Тикет закрыт
   - Тикет назначен
   - Комментарий добавлен

2. **Тернарное выражение** (зеленый)
   - Проверить условие
   - Сравнить значения
   - Логическое И
   - Логическое ИЛИ

3. **Условие** (оранжевый)
   - Если статус равен
   - Если приоритет выше
   - Если время истекло
   - Если исполнитель назначен
   - Если категория равна

4. **Действие** (красный)
   - Отправить уведомление
   - Назначить исполнителя
   - Изменить статус
   - Создать подзадачу
   - Отправить email
   - Изменить приоритет

## Использованные библиотеки

- **ReactFlow** (`reactflow@11.11.4`) - для визуального редактора правил
- **@open-condo/ui** - UI компоненты (Table, ActionBar, Button, Input, Select, Typography)
- **antd** - Grid система (Row, Col)

## Особенности реализации

1. **Кастомные ноды**: Каждый тип ноды имеет свой цвет и набор действий
2. **Select в нодах**: Каждая нода содержит Select с выбором действия
3. **Drag & Drop**: Возможность перетаскивания нод в viewport
4. **Соединения с валидацией**: 
   - Триггер может быть только в начале цепочки
   - Действие может быть только в конце цепочки
   - Тернарные выражения и условия могут быть в середине
   - Нельзя соединять триггер с триггером
   - Нельзя соединять что-либо после действия
5. **Handles (точки подключения)**:
   - Триггер: только source (выход справа)
   - Тернарное/Условие: target и source (вход слева, выход справа)
   - Действие: только target (вход слева)
6. **Анимированные соединения**: Стрелки с анимацией и маркерами
7. **Уведомления об ошибках**: Alert при попытке недопустимого соединения
8. **Controls**: Встроенные элементы управления ReactFlow (zoom, fit view)
9. **Background**: Точечный фон для лучшей визуализации
